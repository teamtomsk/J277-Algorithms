Keyboard help & what the checker checks

Tab to a symbol and press Enter or Space to select it. Use arrow keys to move it in 20-pixel steps. The inspector’s arrow buttons do the same. Use the connection selectors instead of dragging arrows.

The checker checks Start/End, outgoing paths, Yes/No branches and reachability. It does not execute arbitrary text or prove that your calculations are correct. Trace your design with test data as well.

Your canvas is saved in this browser when storage is available. Download editable JSON to keep a portable copy. SVG is a picture of your chart that can be inserted into a document.

06 / Debug & refine

Find the fault. Explain the fix.

Small changes to conditions, counters and arrows can change the whole algorithm. Use a test case to see why each repair matters.

Three constructs to recognise

Sequence: instructions executed one after another.

Selection: a decision chooses a path.

Iteration: arrows take execution back to repeat steps. A condition controls whether it repeats.

Useful boundary tests

  • Balance exactly equals ride cost.
  • No marks before the -1 sentinel.
  • Timer exactly reaches 60 seconds.
  • A loop needs to run more than once.

A decision can control a loop; a diamond on its own does not prove that steps repeat.
