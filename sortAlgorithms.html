02 / Bubble sort

Small swaps. Big changes.

A bubble-sort pass moves left to right, comparing adjacent items. The largest remaining value reaches the end of the unsorted range.

    One pass ≠ one comparison

    A pass is a sweep through the remaining unsorted range. A comparison checks one adjacent pair.

    After each pass, we shorten the range: the final item is already in its correct position.

    When can it stop?

    This version stops after a pass with no swaps, or after at most n − 1 passes.

    A full-width flag version may make an extra no-swap pass to confirm the list is sorted. Always follow the version in the question.

      04 / Merge sort

      Split small. Merge in order.

      A one-item list is already sorted. Merge sort splits down to single items, then combines sorted sublists until one sorted list remains.

      You control the merge

      Both lists are already sorted. Choose the smaller front item, or take from the only list with items left.

      Two key rules

      2. Once a list is empty, copy the remaining items from the other list in order.

      05 / Compare

      Which does less work?

      Compare all three algorithms on exactly the same data. Change its order and size, then see whether your prediction holds.

      Make a prediction, then run the comparison.

      Count the same thing

      A value comparison compares two data values. We do not count loop checks, index tests or animation time.

      The bars show actual comparison counts for these implementations. They are not stopwatch timings.

      The data matters

      Insertion can need little work on nearly sorted data. An optimised bubble sort also stops early on an already sorted list.

      Merge scales well for large mixed lists, but uses extra lists in this implementation. There is no universal winner for every input.

      Spot the algorithm

      Bubble: adjacent indices i and i + 1, swapping and repeated passes.

      Insertion: a saved key, a backwards-moving j and rightward shifts.

      Merge: recursive calls on halves, then two front-item indices and an output list.

      How this relates to the supplied programs

      Insertion follows the supplied shift-and-insert example. Bubble shortens its range and can stop early. Merge uses the same split-and-merge approach with a shorter merge helper. The displayed Python is complete and runnable.
