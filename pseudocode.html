02 / Conditions

A condition gives True or False.

Compare values with ==, !=, <, >, <= and >=. Combine conditions with AND, OR and NOT. Assignment uses = to store a value; a comparison tests a relationship.

Quick reminders

AND: both conditions must be true. OR: at least one must be true. NOT: reverses a Boolean value.

23 DIV 5 → 4 gives the whole-number quotient. 23 MOD 5 → 3 gives the remainder. The runner uses ^ for powers.

    Syntax guide · what this runner supports
    score = int(input("Score"))
print(score)
if score >= 50 then
    print("Pass")
elseif score >= 40 then
    print("Retry")
else
    print("Fail")
endif
for i = 1 to 5 step 1
    print(i)
next i
while score != -1
    score = int(input())
endwhile
do
    score = int(input())
until score == -1
switch score:
    case 1:
        print("One")
    default:
        print("Other")
endswitch
    Also: + − * / ^ DIV MOD, comparisons, AND/OR/NOT, True/False, str(), float(), and // comments. OUTPUT expression and INPUT variable are accepted. FOR endpoints are inclusive. Both quote styles hold text in this runner; the character/string distinction is conceptual.
    Not supported: arrays, file access, user-defined functions/procedures or a full Python program. Runs are bounded to stop runaway loops. random(a,b) includes both integer bounds and uses a repeatable seed here for reproducible practice.

    06 / Debug it
    Make one useful correction.
    Read the faulty fragment, identify the problem and choose a repair. Use a boundary case to explain why the repair matters.
    

    Check these before you run
    • Have you assigned each variable before using it?
    • Does the spelling and capitalisation stay the same?
    • Does every loop make progress towards stopping?
    • Are boundaries such as 100 handled correctly?
    • Is the sentinel excluded from totals and counts?
    • Can a division happen when count is zero?

    Quick check
    One-line recall
    Sequence: execute instructions in order.
    Selection: use a condition or case to choose a path.
    Iteration: repeat a block.
    WHILE: repeat while true; may run zero times.
    DO UNTIL: run once, then repeat until true.
